# 강릉문성고등학교 교과서 선정 서류 만들기

강릉문성고등학교 **검·인정도서 선정 서류**(서식1·2·3)를 화면에서 작성하고 **한글 파일(.hwpx)** 로 내려받는 웹 앱입니다.

원본 한글 서식의 XML 조각을 그대로 품고 있다가 칸에 값만 채워 다시 묶기 때문에, 내려받은 파일은 표·글꼴·도장란이 학교 양식과 100% 같습니다. 한글에서 열어 바로 결재에 올릴 수 있습니다.

로그인·서버가 없습니다. 작성한 내용은 쓰는 사람의 브라우저에만 저장되며 어디로도 전송되지 않습니다.

---

## 만드는 서류

원본: `assets/강릉문성고-원본서식.hwpx`

| 서식 | 내용 | 만드는 사람 | 표 생김새 |
| --- | --- | --- | --- |
| **서식1** 검·인정도서 선정 평가표 | 평가영역·평가기준·항목별 점수 × 출판사 | 평가 위원 각자 | 9행 × 12열 · 0행 출판사명 / 1행 **가격** / 2~6행 평가기준 / 7행 합계 / 8행 종합의견 |
| **서식2** 선정기준 평가 총괄표 | 출판사 × 위원별 점수, 총점·평균·비고 | 교과협의회 (작성자 소속교사 / 확인자 대표교사) | 18행 × 12열 · 0·1열 출판사명·**가격**, 2~8열 위원(7명), 9·10·11열 총점·평균·비고 |
| **서식3** 추천 도서 및 추천 의견서 | 1~3순위 출판사와 추천 의견 | 교과협의회 (작성자 대표교사 / 확인자 교감) | 4행 × 4열 · 순위 / 출판사명 / **가격** / 추천의견 |

본교 양식은 **세 서식 모두 '가격' 칸**을 두는 것이 특징입니다. 위원 화면의 출판사 칸 옆에 가격을 넣으면 서식1 머리글과 서식2·서식3의 가격 칸까지 함께 채워집니다. 숫자만 넣으면 `13,800원` 꼴로 바뀝니다.

### 기본 평가기준 (합계 100점)

| 평가영역 | 배점 |
| --- | --- |
| 교육과정 | 20 |
| 학습내용 선정 | 20 |
| 학습내용 조직 | 20 |
| 교수학습 활동 | 20 |
| 재정적 부분 (필수) | 10 |
| 학습 평가 | 10 |

`[설정]` 화면에서 영역·문구·배점을 바꿀 수 있고, 과목마다 다르게 둘 수도 있습니다. '평가기준' 칸의 기본 문구는 원본 `<참고1> 교과용 도서 평가기준 항목`의 평가기준을 옮긴 것입니다. 재정 항목은 필수 평가요소라 지울 수 없게 잠겨 있습니다.

## 쓰는 차례

1. **위원** — `서류 초안 작성하기` → 이름·과목·출판사(이름과 가격)를 넣고 1순위를 고르면 평가표 초안이 만들어집니다. 점수와 종합의견을 고친 뒤
   - `[한글(hwpx) 저장]` → **서식1** 한글 파일
   - `[인쇄 · PDF 저장]` → 총괄 선생님께 보낼 PDF
2. **교과협의회 대표교사** — `평가총괄표 작성` → 위원들이 보낸 PDF(또는 JSON)를 올리면 점수를 읽어 총괄표를 만듭니다. 출판사 가격을 확인하고, 순위별 추천 의견을 쓴 뒤
   - `[한글(hwpx) 저장]` → **서식2 + 서식3** 한글 파일 하나

평가기준·배점·의견 선택지는 `[설정]` → `설정 JSON 저장`으로 파일에 담아 같은 교과 선생님들과 나눠 쓸 수 있습니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173/munseong-choice/
npm run build
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run forms` | `assets/강릉문성고-원본서식.hwpx` 에서 서식 XML 조각을 다시 뽑아 `public/forms/` 에 넣습니다 |
| `npm run check:hwpx` | 만들어지는 .hwpx 를 실제로 찍어 보고 파일 구성·XML 문법·구역·표 값·칸 주소를 검사합니다 |
| `npm run check:open` | 방금 만든 .hwpx 를 **한글로 실제로 열어** 봅니다 (윈도우 + 한글이 깔린 컴퓨터) |
| `npm run shots` | `npm run dev` 를 띄워 둔 채로 돌리면, 앱을 처음부터 끝까지 움직여 `사용법` 안내 그림 15장을 다시 찍습니다 |

`npm run shots` 는 위원 평가표를 PDF 로 뽑아 그 파일을 총괄 화면에 도로 올리는 식으로 돌기 때문에, '위원 → PDF → 총괄표' 한 바퀴가 실제로 도는지도 함께 확인해 줍니다. 화면이나 서식을 고쳤으면 `npm run shots` 로 안내 그림을 다시 찍어 주세요. 브라우저는 이 컴퓨터에 깔린 크롬/엣지를 그대로 씁니다.

PDF 판독이 어긋날 때는 `node scripts/form1-debug.mjs 평가표.pdf` 로 줄·칸이 어떻게 잡혔는지 볼 수 있습니다.

### 학교 양식이 바뀌면

1. 새 `.hwpx` 를 `assets/강릉문성고-원본서식.hwpx` 로 바꿔 넣습니다.
2. `npm run forms` 로 조각을 다시 뽑습니다.
3. `npm run check:hwpx` 를 돌려 표 크기(행·열 수)가 달라졌는지 봅니다.
4. 달라졌다면 `src/lib/hwpxDoc.ts` 맨 위 주석의 행·열 지도와 `form1`/`form2`/`form3` 의 열 번호를 맞춥니다.
5. `npm run check:open` 으로 한글이 실제로 여는지 봅니다. 한글 창이 잠깐 떴다 닫히고, `빈 문서` 가 뜨면 그 파일을 한글이 읽지 못한 것입니다.

> **구역마다 `<hp:secPr>` 은 딱 하나여야 합니다.** 둘이면 XML 문법도 표도 멀쩡한데 한글만 문서를 열지 못하고 `빈 문서` 를 띄웁니다. 서식2를 잘라 낼 때 실제로 이 일이 있었고(`scripts/hwpx-parts.mjs` 의 `cut()`), 지금은 `npm run check:hwpx` 가 개수를 셉니다.

### 짜임새

```
public/forms/     원본에서 뽑은 서식 XML (form1·form2·form3·header·guide1 …)
src/lib/hwpx.ts      표의 칸 채우기·줄 늘리기·열 지우기·zip 묶기 (양식과 무관한 도구)
src/lib/hwpxDoc.ts   본교 서식1·2·3 의 행·열에 앱의 값을 앉히는 곳  ← 양식이 바뀌면 여기
src/components/Form1Sheet.tsx / Form2Sheet / Form3Sheet   화면·인쇄용 표
src/pages/Personal.tsx   위원 화면        src/pages/Compile.tsx   총괄 화면
src/seed.ts          기본 평가기준·배점, 학교 이름
public/config.json   학교 이름·학년도
```

`public/forms/guide1.xml` 은 원본 `<참고1> 교과용 도서 평가기준 항목` 입니다. 평가기준 기본값을 만들 때 참고했고, 문서에는 넣지 않습니다.

## 배포 (GitHub Pages)

`main` 에 올리면 `.github/workflows` 가 알아서 빌드·배포합니다. **저장소 이름을 정한 뒤 `vite.config.ts` 의 `base` 를 같은 이름으로 바꿔 주세요.**

```ts
base: process.env.BASE_PATH || '/munseong-choice/',
```

예를 들어 저장소가 `munseong-choice` 면 주소는 `https://<계정>.github.io/munseong-choice/` 가 됩니다.
